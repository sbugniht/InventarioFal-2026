🔐 Installa il certificato

Serve una sola volta per dispositivo: permette al browser di fidarsi dell'Assistente Vocale e di usare il microfono.

⬇️ Scarica il certificato

Il certificato vale solo per indirizzi della rete locale: non può essere usato per siti Internet.

📱 iPhone / iPad (usa Safari)

  1. Tocca «Scarica il certificato» e conferma con «Consenti».
  2. Impostazioni → Profilo scaricato → Installa.
  3. Impostazioni → Generali → Info → Impostazioni attendibilità certificati → attiva «Assistente Vocale - CA locale».

🤖 Android

  1. Scarica il certificato.
  2. Impostazioni → Sicurezza → Crittografia e credenziali → Installa un certificato → Certificato CA.
  3. Scegli il file «AssistenteVocale-CA.crt» dai Download.

Il percorso può variare leggermente: cerca «certificato CA» nelle Impostazioni.

🪟 PC Windows

  1. Scarica il certificato e aprilo con doppio clic → Installa certificato.
  2. Scegli «Utente corrente» → «Colloca tutti i certificati nel seguente archivio» → Autorità di certificazione radice attendibili.
  3. Conferma, poi riavvia il browser.

Firefox usa un suo archivio: Impostazioni → Privacy e sicurezza → Certificati → Mostra certificati → Autorità → Importa.

🍏 Altro Mac

  1. Scarica e apri il certificato: si apre Accesso Portachiavi.
  2. Doppio clic su «Assistente Vocale - CA locale» → Fidati → Fidati sempre.

Fatto? Ricarica questa pagina: se il certificato è attivo verrai portato all'Assistente.
